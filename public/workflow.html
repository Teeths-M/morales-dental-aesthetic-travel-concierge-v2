5C
EVN-iQ400™ Environmental Intelligence NEW
LIVE — VERIFIED
What It Does

Continuous real-time environmental risk scoring for the patient's destination country, running from pre-departure through the entire active journey. Pulls from 14 live government advisory feeds (travel-advisory.info, free CORS-enabled API) across all 195 UN member states and converts advisory levels into a Composite Risk Score (0–100). GPS area safety monitor fires an alert if the patient dwells in a flagged neighbourhood for 30+ consecutive seconds — tested online, offline, and in airplane mode. Three-tier fallback: live gov advisory API → 24h localStorage cached intelligence → 200+ keyword neighbourhood threat database. Fully functional with zero connectivity.

Actual Function(s) in Codebase
useEnvironmentalIntelligence (hook — 195-country ISO map, COUNTRY_TIER risk baseline, DESTINATION_CONTEXT profiles, advisoryToRisk, getRiskLevel), GlobalEventBroadcaster (area safety monitor — evnHaversineM, evnReadAreaCache, evnWriteAreaCache, EVN_HIGH_RISK_KEYWORDS 200+ entries), EVNiQ400Card (animated score ring, signal details), EVNiQ400Demo (offline/airplane-mode capable demo), AdminMissionControl (Global Intelligence Ticker — EVN scores for all active patient destinations in parallel)
Data Entities

195-country ISO 3166-1 alpha-2 map, COUNTRY_TIER (4 tiers), 40+ DESTINATION_CONTEXT profiles, 6h sessionStorage advisory cache, 24h localStorage area assessment cache

Output

Composite Risk Score (0–100) + advisory tier label + Live/Offline/Airplane badge + area threat alert (if patient dwells 30s+ in a flagged zone)

Deterministic scoring — no LLM inference. The EVN score is computed from government advisory data + offline tier baseline; it cannot hallucinate. The area safety monitor uses a 200+ keyword threat database covering 30+ countries for offline operation. Timer stored in a ref (not useEffect cleanup) so GPS position updates do not reset the 30-second dwell window.

SYSTEM ARCHITECTURE — WHAT'S ACTUALLY RUNNING

Deterministic Layer (no LLM — rules-based, fully testable)

The SAFE-T4LIFE™ risk engine (Stage 3), procedure/pricing matching (Stage 2), and EVN-iQ400™ environmental scoring (Stage 5C) run on explicit, versioned rules — not model inference. This is the layer that must never hallucinate, and it doesn't, because it isn't a model.

Agentic / LLM-Reasoning Layer (real model calls, with live context)

Doctor & partner verification (Stage 4), visa/compliance checking (Stage 5), and AI Pre-Departure Briefing (Stage 5B) make genuine LLM calls with live internet search and structured outputs — this is the system's real agentic reasoning, correctly scoped to judgment-heavy tasks rather than absolute safety locks.

Human-in-the-Loop Layer

Licensed medical reviewers, care coordinators, doctors, and the patient themselves remain the final decision-makers at every consequential point — Stage 3's waiver signature, Stage 4's manual verification fallback, and Stage 7's explicit patient approval are all logged, auditable human decisions, not automated overrides.

Coordination, Monitoring & Intelligence Layer

The iQ200 handshake engine (Stage 8), 9-Handshake GPS Spine (Stage 9B), active journey monitoring (Stage 9), and EVN-iQ400™ environmental intelligence (Stage 5C) run continuously across the physical journey, with offline SMS fallback for zero-connectivity scenarios — this is real, tested infrastructure, not a planned feature. The Situation Room at /admin/situation-room provides a live tactical world map of all active patient positions, updated every 90 seconds.

Honest Gap — External Travel Booking APIs

Flight, hotel, and ground transport booking automation (Stage 6B) is the one area where the prior workflow draft overstated current capability. Today this is coordinated manually through verified travel agency partners. This is disclosed explicitly rather than folded into a vague "External API Orchestration" claim.
